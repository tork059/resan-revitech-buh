Автоматизация бухгалтерского учёта в 1С

Проект убирает ручные операции бухгалтерии, устраняет нарушения в первичных документах и приводит обмен между торговой и бухгалтерской базами к автоматическому и контролируемому процессу. Работа идёт по одному направлению за раз: обследование, план, внедрение, затем следующее направление.

Цели

  • Данные попадают в бухгалтерскую базу автоматически, без ручной выгрузки и двойного ввода.
  • Первичные документы соответствуют законодательству: счета-фактуры на аванс, адреса обособленных подразделений.
  • Банковские выписки и платёжные поручения обрабатываются без ручного переноса данных.
  • Закрытый период защищён от изменений, отчёты (акт сверки, ОСВ) сходятся с учётом.

Границы и ограничения

  • Основная база остаётся на УТ 10.3, переход на УТ 11 не рассматривается.
  • УТ 10.3 снята с поддержки 1С (с апреля 2024): изменения законодательства вносятся силами проекта.
  • Любые изменения обмена сначала проверяются на копиях баз.
  • Сроки ориентировочные, уточняются по итогам обследования каждого направления.

Вариант Б требует обновить снятую с поддержки доработанную конфигурацию, а правила под 22% всё равно придётся дописывать вручную.

Целевая схема (вариант А)

УТ 10.3Регламентное задание ночью выгружает данные по фиксированному набору правил. Для запуска внешней обработки по расписанию нужна доработка конфигурации. У бухгалтеров нет доступа к выбору правил.
→
Сетевая папка обменаФайл выгрузки. Одна версия правил хранится под контролем администратора 1С.
→
БП 3.0 «Бух. Ресан»Регламентное задание загружает файл. Журнал обмена и уведомление ответственному об ошибках.

Следующий шаг развития: перевести выгрузку за период на регистрацию изменений через собственный план обмена с теми же правилами. Это уберёт повторную выгрузку и основной источник дублей.
